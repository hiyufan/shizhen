# 边缘函数中继（阿里云 ESA）

服务器在海外、又没有国内机器可以当出口时，用这个办法让小红书 / B站等国内平台的请求从国内边缘节点发出。其它办法见[自部署与配置 · 生产部署](self-hosting.md#生产部署)。

## 部署

把 `scripts/esa-relay.js` 部署到阿里云 ESA 边缘函数 / 边缘 Pages，出口在国内边缘节点。改掉里面的 `TOKEN`，然后：

```bash
PARSE_VIDEO_RELAY_CN=https://<函数域名>/relay
PARSE_VIDEO_RELAY_TOKEN=<同一个 TOKEN>
```

国内平台的解析请求由边缘节点代发，跳转仍由本地逐跳做 SSRF 检查。

ESA 上改完代码要在「版本管理」里发布到生产环境，只点「部署」只会更新测试环境。

## 探测边缘出口

要看边缘出口能不能过，先在脚本里填一个单独的 `PROBE_TOKEN`，再开 `https://<函数域名>/probe?token=<PROBE_TOKEN>&xhs=<小红书链接>`。

探测口令别用 `TOKEN`：它会留在浏览器历史和访问日志里，而 `TOKEN` 同时管着中继和图片签名，漏了别人就能拿你的边缘节点当代理。用完把 `PROBE_TOKEN` 清空，探测和其它路径都只回 404，免得被爬虫扫来扫去、拿你的出口 IP 去打平台接口。

## 图片走边缘：`/img`

再设 `PARSE_VIDEO_EDGE_IMG=1`，国内平台（小红书 / 抖音 / 快手 / B站 / 微博）的图片就由浏览器直接从边缘节点的 `/img` 取，不再走「国内 CDN → 海外服务器 → 国内用户」跨两次太平洋；边缘取不到时自动回退到服务器转发。`/img` 只认服务器签过名、未过期的地址，只转白名单里的图片 CDN、只回 `image/*`，不会变成通用代理。

## 视频和音频走边缘：`/media`

再设 `PARSE_VIDEO_EDGE_MEDIA=1`，视频和音频（预览、拖进度条、下载、iPhone 存相册）也从边缘节点的 `/media` 取。这部分原来占全站流量的六成，都要跨两次太平洋；边缘播不了时页面自动退回服务器转发。`/media` 同样只认签过名的地址，只转白名单里的音视频 CDN，只回音视频。这部分流量会算在 ESA 上，开之前看一眼套餐额度。

服务器到中继走 HTTP/2，一次解析里并发的几个请求共用一条焐热的连接。

## 局限

中继只是 HTTP 转发，不是真正的代理，yt-dlp 走不了它，所以 B站 只有上游解析器的 480p 直链，1080p 合并下载仍取决于服务器自身出口。

国内边缘出口仍可能被平台要求登录或返回安全限制。小红书匿名笔记长链接会优先尝试官方 `rednote.com` 手机页，保留链接参数并核对笔记 ID；短链先按原跳转解析，失败后可用跳转中取得的笔记长链尝试该入口。这个路径不需要账号或手机连接，仍不保证已删除、私密或所有过期凭证都能恢复。
