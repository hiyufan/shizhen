# 横幅广告

工具首页与平台落地页在解析结果、转换器之后，正文说明之前放置一个标注“广告”的横幅。桌面宽度至少 860px 时使用 728×90；其余至少 320px 的屏幕使用 320×50。更窄的屏幕不加载广告。预留高度，成功、空响应、拦截或超时都不改变占位尺寸；清空或重新解析不重复请求广告。

两个广告位使用站长提供的 `bauval.org` 代码，定义在 `web/ads.py` 的固定列表中。`PARSE_VIDEO_ADS=0` 可在重启应用后关闭展示和广告帧入口；默认开启。移动端和桌面端的素材、投放与收益由广告平台管理，不根据脚本加载成功推断曝光或收入。

额外的 `https://quge5.com/88/tag.min.js` 标签按站长提供的原样放在广告文档的 `<head>` 后，保留 `data-zone="302981"`、`async` 和 `data-cfasync="false"`。仅广告文档的脚本来源增加 `https://quge5.com`；主页面不执行该脚本，沙箱不授予同源或顶层文档访问权限。供应商若依赖这些权限，相关功能可能不可用，不能以扩大主页面权限作为自动兜底。

2026-10-28 的真实脚本检查中，该标签继续请求 `auqot.com`、`ekhay.com`、`b3mny.com` 的脚本，均被广告文档的脚本来源策略阻止。因此标签可加载不代表其全部广告格式已经启用；额外来源及需要主页面权限的功能仍需单独确认。

站长提供的 `sw.js` 原样托管在网站根路径 `/sw.js`，当前文件配置为 `5gvci.com`、zone `12140625`。本站代码不主动注册该 Service Worker；文件可下载与广告商运行成功、通知授权或广告填充是不同的验证项。

主页面只加载本站的 `advertising.js` 模块，不执行广告商脚本，也不放宽原有 CSP。模块按屏幕创建 `/api/ads/desktop` 或 `/api/ads/mobile` 文档，浏览器延迟加载。广告文档保留原有站点鉴权，不进搜索引擎，不计页面浏览，不读取或传递粘贴的链接、解析结果和来源 Cookie。

框架的 sandbox 只允许脚本和弹出新窗口，不授予 `allow-same-origin`、顶层导航、表单、下载或设备访问权限。独立文档的 CSP 仅允许本站配置脚本和 `https://bauval.org` 的广告脚本，动态广告框及素材限 HTTPS；不允许内联脚本或 eval。帧内 `ad-frame-bootstrap.js` 必须作为外部经典脚本先执行，提供同步 `atOptions`，再执行广告商原始脚本，以保留其 `document.write` 兼容性。

广告框通过固定类型的 postMessage 报告是否创建并加载了内容框；主页面核对消息来源窗口与状态枚举，不接收 HTML、跳转地址或任意尺寸。未创建内容框时在超时后展示“广告暂不可用”。内容框 load 事件不能证明实际填充、可见曝光或计费成功。

本地浏览器检查使用广告脚本替身验证同步配置、沙箱隔离、宽窄屏切换、无填充、超时、清空和换链接，不点击真实广告；真实投放仍需在平台允许的正式域名检查。接入时实际域名曾返回空脚本或 403，不能把替身展示当作平台已经填充广告。
