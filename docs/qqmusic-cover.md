# QQ 音乐封面：来源与验证范围

歌曲、专辑分享链接返回静态封面，并检查公开的专辑封面视频。歌单只读取自己的封面，不借用列表中歌曲的封面。不请求歌曲音频。

## 已处理的来源

| 数据来源或情况 | 行为 |
| --- | --- |
| `basicInfo.dynamicCoverVid` | 优先读取专用动态封面 |
| `basicInfo.headVideoVid` | 专用封面不可用时检查专辑头图；要求网关标记 `videoType=8`，时长大于 0 且不超过 120 秒 |
| `basicInfo.headMediaList[].vid` | 同样校验封面类型与时长；跳过重复、空和无效项后，最多查询 4 个不同 VID，最多扫描前 32 个头图条目 |
| MP4 档位与备用地址 | 按平台档位编号选最高可用 MP4；检查 `freeflow_url`、`url`、`comm_url`、`validUrl`，仅收可信腾讯音乐视频 CDN 的完整地址 |
| 部分字段、候选视频或档位异常 | 跳过该项，继续查其余候选；高档位无地址时使用实际可用的低档位 |
| 网关失败、没有公开封面视频、附加查询超时 | 保留静态封面；解析成功不代表动态视频也已取得 |
| `basicInfo.vid`、宣传片、MV、歌词本 | 不当作封面动画 |
| `threeDUrl` 等交互页面 | 尚未提供 3D 场景渲染；页面地址不能直接当视频下载 |

专辑身份目前从图片路径中的 `T002…M000{albumMid}` 读取，兼容版本后缀及 JPG / JPEG / PNG / WebP / AVIF 文件名。自定义文件名没有专辑 MID 时不能据此查出动态封面；上述文件名兼容由离线测试覆盖，不代表已取得每种编码的真实 QQ 样本。

下载时重新读取专辑信息和限时地址，不缓存过期签名。原始视频和转换产物仍经过现有下载校验、签名、资源配额与取消机制。

## 两种下载版本

- **方形动态封面**：从中心裁切，不添加边框；保留源帧时序，编码为 H.264 Baseline，作为默认转换输入。
- **完整原版**：保留完整画面及来源自带的上下色带，视频流复制，不重新编码。保留原始帧时间，去掉音轨。

GIF / iPhone 实况 / 安卓动态照片沿用转换流程；输出受片段、尺寸和格式限制，不能称为原文件。实体手机的系统相册导入需另行验证。

## 2026-11-14 核验

匿名读取 8 位歌手专辑列表中的 236 张不同专辑，逐张检查公开 `GetAlbumDetail` 的封面字段。其中 5 张返回了封面视频候选，全部从 `GetMvUrls` 取得可用 MP4；另外 231 张在本次公开响应中没有上述候选，不能据此断言客户端中一定没有动态效果。样本未出现非空 `threeDUrl`。

| 专辑 | 专辑 MID | 公开视频来源 |
| --- | --- | --- |
| 薛之谦《天外来物》 | `000K9Zp13TZp5s` | 专用动态封面、专辑头图 |
| 陈奕迅《黑白灰》（含《十年》） | `000GDz8k03UOaI` | 仅专辑头图 |
| G.E.M.邓紫棋《喜欢你》 | `000cFPKx3ZGzks` | 专用动态封面、专辑头图 |
| G.E.M.邓紫棋《新的心跳》 | `003c616O2Zlswm` | 专用动态封面、专辑头图 |
| Adele《30》 | `004gAmZG1Gg2YD` | 专用动态封面、专辑头图 |

5 张专辑均经正式解析器返回两个下载版本，完整下载原版与方形版，共 10 份 MP4。实际尺寸分别为 1080×1440 / 1080×1080（《天外来物》《喜欢你》《新的心跳》）、480×480 / 480×480（《黑白灰》）、2160×2880 / 2160×2160（《30》）。所有文件从 0 秒开始，两版本分别保留相同的 76 / 150 / 151 / 151 / 375 帧和源时长，完整解码通过，方形版为 Baseline。

每张方形版另截取 2 秒，生成 GIF、iPhone 实况和安卓动态照片，共 15 份产物；校验 GIF 多帧、JPG / MOV 标识配对和动态照片内嵌视频标记。《意外》另经真实解析确认仍只呈现静态封面。外网验证期间遇到过页面读取超时，重试后通过；未验证微信真机保存或实体手机相册导入。

上述 5 张专辑的脱敏公开响应保存在 `tests/fixtures/qqmusic_artwork.json`，回归核对来源优先级和最高可用档位。备用地址、坏字段、列表占位、宣传片和交互页面另有离线反例；这些替身用例不算新增类型的真实平台验证。此清单用于记录已核对的范围，不承诺平台所有作品、账号专属效果或未来字段均已支持。
